# 🌍 The Problem

Every day, perfectly usable food can become surplus because of:

- Overproduction
- Events
- Restaurants
- Hotels
- Corporate cafeterias
- Retail operations
- Household surplus
- Supply-chain inefficiencies
- Short shelf windows

At the same time, food insecurity remains a serious social challenge.

This creates a powerful but difficult systems problem:

```text
          SURPLUS FOOD
                │
                ▼
        ┌───────────────┐
        │   AVAILABLE   │

                │

                │
                ▼

                │
                ▼
          HUMAN IMPACT

The challenge is not simply discovering surplus food.

The real challenge is:

Matching the right food to the right recipient at the right location before the opportunity expires.

🧠 The Core Insight

Food redistribution is fundamentally a time-sensitive matching problem.

A normal marketplace asks:

What is available?

Vital Victuals asks:

What is available?
        +
Where is it?
        +
How much is available?
        +
Who needs it?
        +
Where are they?
        +
How urgent is it?
        +
How long will it remain usable?
        +
Can it be transported in time?
        ↓
What is the best action NOW?

That is the intelligence layer behind the product.

🚀 Getting Started
Requirements

Install:

Node.js
npm
Git

Check your environment:

node --version
npm --version
git --version
1️⃣ Clone the Repository
git clone https://github.com/himanshuguptastudiesiitp/vital-victuals.git

Enter the project directory:

cd vital-victuals
2️⃣ Install Dependencies
npm install

This installs the dependencies defined by the project.

3️⃣ Start Development Server
npm run dev

Vite will start the local development environment and display the local URL in the terminal.

A typical Vite development URL is:

http://localhost:5173
4️⃣ Build for Production
npm run build

This generates the production-ready frontend build.

5️⃣ Preview Production Build
npm run preview

This allows the production build to be locally previewed before deployment.

🎨 Product Design Principles
01 — Action Before Complexity

The user should understand what to do immediately.

02 — Time Matters

Food redistribution is time-sensitive.

03 — Distance Matters

A perfect donor-recipient match is useless if delivery is impractical.

04 — Impact Matters

The platform should measure outcomes rather than simply count transactions.

05 — Human-Centered AI

AI should improve decisions instead of making the user experience confusing.

06 — Operational Simplicity

Complex logistics should feel simple to the user.
